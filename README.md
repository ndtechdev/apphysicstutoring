# # AP Physics Prep Tutoring Website

This is a professional website for an AP Physics Prep tutoring program created by Nishtha and Ojal. The website gives students and parents information about the class, topics covered, pricing, policies, feedback form, and contact options.

## Website Overview

The AP Physics Prep program is designed to help high school students build a strong foundation before starting AP Physics. The class focuses on prerequisite math skills, physics concepts, and problem-solving strategies.

## Features

- Professional light theme with navy blue accents
- Clickable tab-style navigation
- Home page with class overview
- About Us section
- Program topics section
- Rates and payment information
- Referral discount information
- Class policy section
- Feedback form link
- Contact and sign-up section
- Mobile-friendly layout

## Class Details

- **Class Length:** 1 hour 30 minutes
- **Schedule:** 2 times per week
- **Time:** 7:30 PM
- **Cost:** $120 per month
- **Cost per Class:** About $15 per class

## Topics Covered

The program introduces and reviews important skills needed for AP Physics, including:

- Algebra for physics
- Trigonometry basics
- Vectors and components
- Graph reading
- Motion and kinematics
- Forces and Newton’s Laws
- Energy
- Momentum
- Circular motion
- Torque
- Waves
- Problem-solving strategies

## Payment Options

Students can pay through:

- Venmo
- PayPal
- Zelle

Payment is due at the beginning of each month.

## Referral Discount

Students who refer a friend to the AP Physics Prep program can receive a referral discount.

If a student refers a friend and the friend joins the program, both students receive **$15 off the first month**.

## Class Policies

- Students pay monthly through Venmo, PayPal, or Zelle.
- Payment is due at the beginning of each month.
- If a student is absent, a recorded video and class materials will be sent in the group chat.
- Homework assignments are due the day before the next class.
